# حكواتي AI — النسخة 0.1

هذه نسخة تطوير حقيقية فيها:
- واجهة عربية.
- سيرفر Node.js يحفظ مفتاح HeyGen بعيدًا عن المستخدم.
- تحميل قائمة الشخصيات والأصوات من HeyGen.
- إرسال نص عربي لتوليد فيديو.
- فحص حالة الفيديو عبر API.

## مهم جدًا
لا تضع مفتاح HeyGen داخل index.html ولا ترسله لأي شخص.
ضعه فقط في ملف `.env` على جهازك/السيرفر.

## التشغيل على الكمبيوتر
1. فك الضغط.
2. ثبّت Node.js 18 أو أحدث.
3. افتح المجلد في Terminal.
4. شغّل:
   npm install
5. انسخ `.env.example` إلى `.env`
6. داخل `.env` اكتب مفتاحك مكان:
   HEYGEN_API_KEY=...
7. شغّل:
   npm start
8. افتح:
   http://localhost:3000
